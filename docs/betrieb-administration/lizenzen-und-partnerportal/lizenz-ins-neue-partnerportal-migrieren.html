Lizenz ins neue Partnerportal migrieren

Letzte Änderung 12.11.2026 · Version 2 · Seiten-ID 960

Kassen und CentralPoint-Installationen, die noch mit dem alten Lizenzsystem (Puck) laufen, stellen Sie über einen Eintrag in der Konfigurationsdatei auf das neue Partnerportal um. Beim nächsten Start holt sich die Anwendung automatisch eine neue Lizenz.

Voraussetzungen

  • Die alte Lizenz ist im alten Partnerportal Ihrem Partner-Account zugeordnet. Nur dann wird die neue Lizenz im neuen Partnerportal für Sie erstellt.
  • Die Kasse bzw. der CentralPoint-Rechner hat eine Internetverbindung.

So gehen Sie vor

ITR Kasse

  1. Öffnen Sie an der Kasse die Datei C:\GoodCompany\Kasse\cr.properties.
  2. Ergänzen Sie folgende Zeile:
    Properties
    Misc.UseNewLicenseSystem=true
  3. Starten Sie die Kasse. Beim Start migriert sie die Lizenz in das neue Partnerportal und erhält automatisch eine neue Lizenz.
  4. Starten Sie danach den Rechner neu oder starten Sie den Dienst ALVARAErpSync neu.

Melden mehrere Windows-10-Kassen dieselbe Kennung (Geräte ohne Sysprep ausgeliefert), ergänzen Sie zusätzlich Misc.UseCrAndBranchIdForId=true. Die Kennung wird dann aus Kassen- und Filialnummer gebildet.

CentralPoint

  1. Öffnen Sie auf dem CentralPoint-Rechner die Datei C:\GoodCompany\itrCP\sync\syncer.properties.
  2. Ergänzen Sie folgende Zeile:
    Properties
    useNewLicenseSystem=true
  3. Starten Sie den Dienst ALVARAErpCPSync und den CentralPoint neu.
  4. Wählen Sie im CentralPoint in der Lizenzübersicht Lizenz aktivieren.

Halten Sie die Schreibweise useNewLicenseSystem genau ein: kleines „u“ am Anfang. Eine abweichende Schreibweise wird ohne Fehlermeldung ignoriert, die Lizenz bleibt im alten System.

Ergebnis prüfen

  • Partnerportal: Die neue Lizenz erscheint unter Ihrem Partner-Account und lässt sich dem Endkunden zuweisen.
  • ITR Kasse: Unter Admin-Seiten → Einstellungen → Admin → Lizenz stehen die freigeschalteten Module.
  • CentralPoint: Der Lizenzschlüssel in der Lizenzübersicht hat sich geändert.

Wenn es nicht funktioniert

  • Keine neue Lizenz im Partnerportal: Prüfen Sie im alten Partnerportal, ob die alte Lizenz Ihrem Partner-Account zugeordnet ist.
  • Lizenzschlüssel im CentralPoint ändert sich nicht: Schreibweise des Eintrags prüfen, danach Dienst und CentralPoint erneut neu starten.
  • Kasse im Netz mit Proxy: ITR Partner Service → FAQ & Troubleshooting → Kasse hinter einem Proxy: keine Lizenz- und Clouddaten
