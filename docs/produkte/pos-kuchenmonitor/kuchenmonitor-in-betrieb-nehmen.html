Küchenmonitor in Betrieb nehmen

Letzte Änderung 11.10.2026 · Version 3 · Seiten-ID 753

Installation, Freigabe der Ports und Kopplung mit den Kassen.

Voraussetzungen

  • Ein Windows-Rechner mit Bildschirm in Küche oder Bar. Bei Windows 11 Pro N wird das Media Feature Pack benötigt.
  • Die Kassen der Filiale sind im selben Netz erreichbar.
  • An den Artikeln ist ein Ziel hinterlegt — Küche, Bar oder beides.

Ports

Port Richtung Zweck
8080 TCP Küchenmonitor → Kasse Standardverbindung zur Kasse, im Setup voreingestellt
2680 TCP eingehend am Küchenmonitor Empfang der Bestellungen von der Kasse, Abfrage durch den Abholmonitor und Erreichbarkeitsprüfung der Kasse
8086 TCP eingehend am Küchenmonitor Benachrichtigung des Abholmonitors

Auf dem Küchenmonitor selbst ist Port 8080 nicht offen — dort ist er Client. Der Listener läuft auf der Kasse. Das ist bei der Fehlersuche der häufigste Irrtum.

Das Setup legt die Regeln in der Windows-Firewall selbst an: eingehend 2680 und 8086, ausgehend 8080. Von Hand freigeben müssen Sie die Ports nur bei einer anderen Firewall.

Der Abholmonitor öffnet keine Ports. Er verbindet sich nur ausgehend über 2680 und 8086 mit den Küchenmonitoren.

So gehen Sie vor

  1. Setup ausführen. Starten Sie KimoSetup-<Version>.exe mit Administratorrechten. Installiert wird nach C:\GoodCompany\Kitchen Monitor\, mit Verknüpfungen auf dem Desktop, im Startmenü und im Autostart. Dasselbe Setup gilt für Küchen- und Abholmonitor.
  2. Firewall prüfen. Die Regeln für 2680, 8086 und 8080 legt das Setup an. Bei einer anderen Firewall geben Sie die Ports dort frei.
  3. Betriebsart wählen. Beim ersten Start wählen Sie Küchenmonitor oder Kundendisplay (Abholmonitor). Pro Rechner ist nur eine Betriebsart möglich.
  4. Setup-Wizard durchlaufen. Er sucht die Kassen und Kiosks im Netz. Dort wird der Bereich festgelegt — Küche, Bar oder beides — und die Verbindungsadresse gewählt oder von Hand eingetragen.
  5. Kopplung prüfen. Nach dem Setup trägt sich der Küchenmonitor auf der Kasse ein und ist damit allen Kassen der Filiale bekannt.
  6. Abholmonitor einrichten, falls gewünscht: Beim ersten Start sucht er das Netz nach Küchenmonitoren; mindestens einer wird ausgewählt, dazu die Anzeigeart — Kunden- oder Bedienerdisplay.

Optional: Liegt eine Datei Background.png neben kimo_flutter.exe, verwendet der Abholmonitor sie als Hintergrund. Ohne Datei zeigt er die Standardansicht mit farbigen Kopfzeilen. Das Setup liefert die Datei nicht mit; bei Update und Deinstallation bleibt sie erhalten.

Ersetzt der Abholmonitor eine ältere Installation, werden deren Einstellungen nicht übernommen. Richten Sie ihn einmal neu ein und entfernen Sie danach den alten Ordner und seine Verknüpfungen.

Der Abholmonitor spricht ausschließlich mit dem Küchenmonitor — Kasse und Synchronisationsdienst sind daran nicht beteiligt. Mehrere Verbindungen sind möglich.

Ergebnis prüfen

  • Eine Bestellung mit einem Artikel mit Küchenziel erscheint auf dem Monitor.
  • Der Status lässt sich durch Antippen weiterschalten.
  • Der Abholmonitor zeigt die Bestellung an und wechselt bei Statusänderung mit.

Update

Führen Sie das neue Setup aus. Es entfernt die alte Version und installiert die neue. Einstellungen, Datenbank und Background.png bleiben erhalten; die Datenbank wird automatisch angepasst.

  • Läuft das Programm während des Updates, erscheint der Windows-Hinweis auf verwendete Dateien. Starten Sie das Programm danach neu.
  • Eine ältere Version lässt sich nicht über eine neuere installieren. Deinstallieren Sie vorher.
