Lagerverwaltung einrichten

Letzte Änderung 29.08.2026 · Version 1 · Seiten-ID 782

Die Lagerverwaltung führt Bestände artikelgenau. Der CentralPoint pflegt dabei die artikelbezogenen Einstellungen und wertet die Bestände filialübergreifend aus; das Grundverhalten wird an jeder Kasse gesetzt.

Voraussetzungen

  • Der CentralPoint ist installiert, registriert und mit der zentralen Datenbank verbunden.
  • Die betroffenen Kassen sind mit dem CentralPoint verbunden und synchronisieren.
  • Für Auswertungen über Eigene Berichte: das Modul Erweiterte Berichte ist lizenziert.

Wer was einstellt

Ort Was dort festgelegt wird
ITR Kasse, Admin-Panel ob die Lagerverwaltung überhaupt greift und wie Bestände angezeigt werden
CentralPoint, Artikel Details ob ein einzelner Artikel Bestand führt, Chargengröße, Produktionsdauer, Produktionshinweis
CentralPoint, Bon-Typen wie ein Vorgang den Bestand verändert

Solange an einer Kasse Lager aktiv nicht gesetzt ist, bleiben alle im CentralPoint gepflegten Lagereinstellungen wirkungslos. Weder Bestandslogik noch Produktionsablauf greifen dann.

So gehen Sie vor

  1. An jeder Kasse im Admin-Panel Einstellungen → Bon → Lager öffnen und Lager aktiv setzen. Die übrigen Optionen dort steuern negative Bestände und die Anzeige auf den Artikelknöpfen.
  2. Im CentralPoint die Bon-Typen prüfen: Am Bon-Typ legt die Einstellung Warenbestandsveränderung fest, wie ein darüber gebuchter Vorgang den Bestand beeinflusst.
Wert Wirkung auf den Bestand Typischer Einsatz
Erhöhung Bestand steigt um die gebuchte Menge Lieferung, Wareneingang
Verringerung Bestand sinkt um die gebuchte Menge Verkauf; Vorgabe bei Bon-Typ 0
Überschreiben Bestand wird auf die gebuchte Menge gesetzt Inventur, Korrektur
  1. Im CentralPoint je Artikel den Dialog Artikel Details, Reiter Lagerverwaltung öffnen und pflegen:
Feld Bedeutung
Lagerverwaltung deaktivieren nimmt diesen Artikel je Filiale von der Bestandsführung aus
Chargengröße Größe einer Produktions- oder Backcharge. Wird der Bestand darunter geführt, fordert die Kasse zum Produzieren auf
Produktionsdauer Produktions- oder Backdauer in Minuten
Produktionshinweis Hinweistext, der der Verkaufskraft beim Unterschreiten der Chargengröße angezeigt wird
  1. Die Stammdaten an die Kassen verteilen und einen Synchronisationslauf abwarten.

[SCREENSHOT: CentralPoint → Artikel Details, Reiter Lagerverwaltung]

Produktionsablauf ergänzen

Ist die Lagerverwaltung aktiv und am Artikel eine Chargengröße gepflegt, unterstützt die Kasse einen Nachproduktions-Ablauf. Fällt der Bestand unter die Chargengröße, meldet die Kasse Produktionsbedarf; die Verkaufskraft wählt Jetzt produzieren oder Später produzieren. Produzierte Mengen lassen sich auch von Hand über den Lagerdialog einbuchen.

Das Verhalten steuern drei Parameter an der Kasse:

Parameter Standardwert Wirkung
Stock.showProductionMessages false schaltet die automatischen Fertigstellungs-Hinweise nach Ablauf der Produktionsdauer ein. Der Hinweis erscheint nicht, solange ein Bon mit Positionen offen ist
Stock.SuspensionInMinutes 3 Wartezeit in Minuten, bis ein mit Später produzieren aufgeschobener Auftrag erneut vorgelegt wird
Stock.PrintReceiptType leer Code eines Bon-Typs. Ist er gesetzt, wird bei Jetzt produzieren ein Produktionsbon gedruckt

Stock.PrintReceiptType erwartet den Code des Bon-Typs, nicht Name oder Kennung. Ein falscher Wert führt dazu, dass kein Produktionsbon gedruckt wird — ohne Fehlermeldung.

Ein weiterer Parameter betrifft nur die Anzeige: Stock.NullCharacter legt das Zeichen fest, das auf dem Artikelknopf für Artikel ohne Lagerverwaltung erscheint. Standardwert ist -; für gar keine Anzeige wird ein Leerzeichen gespeichert.

Diese Parameter werden an der Kasse gepflegt — siehe ITR Partner Service → Produkte → ITR Kasse → Einstellungen der Kasse: Referenz.

Bestände aus einem Fremdsystem übernehmen

Liefermengen aus einem Vectron-Bericht lassen sich über den GoodCompanyDaemon als Lagermengen einspielen. Der Job VectronStockImporter übernimmt dazu den 121er Vectron-Bericht:

Text
call:VectronStockImporter
#stockField=104_30_1
#addTag=Handelswarenzubuchung

Parameter und Varianten stehen in ITR Partner Service → Produkte → GoodCompanyDaemon → Daemon Jobs: Referenz.

Auswertungen

Über Eigene Berichte lassen sich lager- und warenwirtschaftsbezogene Auswertungen zusammenstellen, etwa Bestellungen, Retouren und Bruch oder Filialübersichten. Siehe ITR Partner Service → Produkte → CentralPoint → Kassenberichte und Auswertungen.

Ergebnis prüfen

  1. An einer Kasse einen Artikel mit gepflegter Chargengröße bonieren.
  2. Der Bestand des Artikels sinkt um die gebuchte Menge.
  3. Ist die Anzeige auf den Artikelknöpfen eingeschaltet, ändert sich der auf dem Knopf gezeigte Wert.
  4. Unterschreitet der Bestand die Chargengröße, erscheint der Produktionsdialog mit dem hinterlegten Produktionshinweis.
  5. Ein Vorgang über einen Bon-Typ mit Erhöhung hebt den Bestand wieder an.

Wenn es nicht funktioniert

  • Bestände bewegen sich nicht: an der betreffenden Kasse prüfen, ob Lager aktiv gesetzt ist.
  • Ein einzelner Artikel führt keinen Bestand: im CentralPoint prüfen, ob am Artikel Lagerverwaltung deaktivieren gesetzt ist — die Einstellung wirkt je Filiale.
  • Verkauf verändert den Bestand nicht wie erwartet: die Warenbestandsveränderung des verwendeten Bon-Typs prüfen.
  • Kein Produktionsbon: Stock.PrintReceiptType gegen den Code des Bon-Typs prüfen.
  • Neue Artikeleinstellungen kommen nicht an: Synchronisationszustand der Kasse prüfen — siehe ITR Partner Service → Produkte → ITR Kasse → Daten von Hand synchronisieren.
