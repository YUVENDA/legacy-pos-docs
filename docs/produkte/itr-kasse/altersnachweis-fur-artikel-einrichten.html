Altersnachweis für Artikel einrichten

Letzte Änderung 13.11.2026 · Version 5 · Seiten-ID 936

Für Artikel mit Altersgrenze (z. B. Tabak, Alkohol) fragt die ITR Kasse beim Bonieren nach, ob der Kunde alt genug ist. Die Abfrage wird am Artikel hinterlegt.

Voraussetzungen

  • Zugriff auf die Artikelstammdaten im CentralPoint

So gehen Sie vor

  1. Öffnen Sie im CentralPoint Kassendaten → Artikel und wählen Sie den Artikel.
  2. Tragen Sie im Bereich Sonstiges im Feld Altersnachweis die Altersgrenze ein, z. B. 18.
  3. Speichern Sie den Artikel und übertragen Sie die Stammdaten an die Kassen.

An einer Standalone-Kasse ohne CentralPoint pflegen Sie das Feld im Artikeldialog der Kasse. Er ist genauso aufgebaut wie im CentralPoint.

Verhalten an der Kasse

Situation Verhalten
Erster Artikel mit Altersnachweis auf dem Bon Dialog Altersnachweis – Bitte bestätigen Sie… mit den Schaltflächen Kunde ist mindestens 18 Jahre alt! und NEIN
Bestätigt Artikel wird gebucht.
NEIN Artikel wird nicht gebucht.
Weitere Artikel mit Altersnachweis auf demselben Bon – gleicher oder anderer Artikel keine erneute Abfrage
Neuer Bon Abfrage erscheint wieder beim ersten betroffenen Artikel.
Kundendisplay Der Dialog erscheint nur auf dem Bedienerbildschirm.

Die Abfrage erfolgt also einmal je Bon, beim Bonieren und vor der Zahlung. Die bestätigte Altersgrenze wird am Bon gespeichert (ipos_receipts.PROOF_OF_AGE).

Ergebnis prüfen

  1. Bonieren Sie den Artikel an der Kasse: Der Dialog Altersnachweis erscheint.
  2. Bonieren Sie denselben Artikel ein zweites Mal: Er wird ohne Abfrage gebucht.

Zu beachten

  • Kommen die Artikel aus einer Warenwirtschaft, muss diese das Feld Altersnachweis liefern. Sonst wird es beim nächsten Import überschrieben bzw. bleibt leer.
  • Zeigt die Kassenmaske zusätzlich eine eigene Altersabfrage (z. B. nach der Zahlung über eine Taste im Kassen-Designer), wird doppelt gefragt. Verwenden Sie nur einen der beiden Wege.
